Lade …
An = online, Werte gehen raus · Offline = Verbindung reißt ab wie bei Stromausfall (der Broker meldet offline, die letzten Werte bleiben) · Aus = nichts senden, die Topics werden gelöscht. Änderungen gehen sofort raus und bleiben beim nächsten Start erhalten. ⚙ = Einstellung, kein Messwert. Läuft das echte Gerät am selben Broker, hier auf Aus stellen.
Szenarien
Ein Szenario ändert die Werte über die Zeit. Stopp stellt die Werte von vorher wieder her, Stopp & behalten lässt den Endstand stehen.
Eigene Szenarien
Szenarien als JSON herunterladen, als Vorlage ändern (neue id) und wieder hochladen. Neue kommen zur Liste dazu, eigene mit gleicher id werden ersetzt. Die Standard-Szenarien bleiben immer erhalten. Format: tools/emulator/README.md, Abschnitt „Eigene Szenarien“. Gespeichert in tools/emulator/data/scenarios/.
Empfangene Befehle
Noch keine. Am Display z. B. die Heizung schalten.
Aufräumen
Löscht alle retained Topics, die der Emulator gesendet hat, und sendet danach die eingeschalteten Geräte neu. Beim Beenden mit Strg+C passiert das von selbst (außer mit --keep).
