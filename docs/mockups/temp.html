Sensoren
Noch keine Sensoren. Unten aus der Liste der gefundenen Geräte übernehmen.
Die ID ist das MQTT-Topic: camper/temp/<id>. Erlaubt sind a-z, 0-9, _ und -. Der Offset wird zum Messwert addiert.
Alarm: Wert liegt länger als die Verzögerung unter bzw. über der Grenze. Er geht weg, sobald der Wert 0,5 °C zurück im Bereich ist. Leeres Feld = kein Alarm. Topic <prefix>/<id>/alarm, Text für Displays unter <prefix>/alarm_text, alle Werte als JSON unter <prefix>/sensors.
Gefunden am 1-Wire-Bus
Rohwerte ohne Offset. Welcher Sensor welcher ist: einen in der Hand anwärmen und zusehen, welcher Wert steigt.
Messung
Nach jeder Messung werden die Werte per MQTT gesendet, spätestens aber jede Minute.
MQTT Settings (Home Assistant)
Werte unter <prefix>/<id>, Status unter <prefix>/status
